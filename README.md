# AutoCopy

Программа для Windows, которая работает в трее и копирует выделенный текст сама, без Ctrl+C.
После каждого копирования звучит сигнал и появляется уведомление.

## Как это работает
1. Программа следит за левой кнопкой мыши во всей системе.
2. Если вы протянули мышь с зажатой кнопкой (≥ 6 px) или сделали двойной/тройной щелчок, через ~0,1 с программа сама нажимает Ctrl+C. Клавиша C отправляется по коду клавиши, поэтому всё работает и в русской раскладке.
3. По счётчику изменений буфера обмена (`GetClipboardSequenceNumber`) программа проверяет, что приложение действительно что-то скопировало. Если ничего не выделено, буфер не трогается и уведомления нет.
4. Если в буфере оказался непустой текст, звучит системный сигнал и появляется уведомление Windows с началом текста.

## Запуск
```bat
pip install -r requirements.txt
pythonw auto_copy.py
```
Сборка в `.exe`: запустите `build.bat`, готовый файл появится в `dist\AutoCopy.exe`.

## Меню в трее (правая кнопка мыши)
- Включить или выключить автокопирование. Двойной щелчок по значку делает то же самое; когда копирование выключено, значок серый.
- Включить или выключить звуковой сигнал.
- Включить или выключить всплывающие уведомления.
- Запуск вместе с Windows (через реестр HKCU\…\Run, права администратора не нужны).
- Открыть или перечитать настройки в `%APPDATA%\AutoCopy\config.json`.
- Выход.

## Настройки (`config.json`)
| Параметр | Что задаёт |
|---|---|
| `min_drag_px` | минимальная длина протягивания мыши |
| `multi_click_ms` | интервал для двойного/тройного щелчка |
| `preview_chars` | сколько символов показывать в уведомлении |
| `excluded_processes` | программы, где автокопирование не работает |

## Ограничения
- В терминалах (cmd, PowerShell, Windows Terminal) автокопирование по умолчанию выключено: там Ctrl+C прерывает выполняемую команду. В проводнике оно тоже выключено, чтобы при перетаскивании не копировались файлы. Список можно изменить в настройках.
- Если в момент отпускания мыши зажаты Shift, Ctrl, Alt или Win, копирование пропускается: иначе получилось бы другое сочетание клавиш, например Ctrl+Shift+C открывает DevTools в браузере.
- Если протянуть мышь там, где выделения нет (окно, полоса прокрутки), программа всё равно отправит Ctrl+C. Обычно это ничего не меняет.
- Программы, запущенные от имени администратора, не получают нажатия от обычного процесса. Чтобы копирование работало и в них, запустите AutoCopy тоже от администратора.
- Каждое выделение заменяет содержимое буфера обмена, как и обычный Ctrl+C.
